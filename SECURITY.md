# Security

Flyweight has no accounts, payments, or user data storage, and requires no
secrets to run locally. Threat-model rules for this project are in
`AGENTS.md`; this file records current audit status.

## Reporting

This is a local research/demo project with no public deployment yet. If you
find a security issue, open an issue in this repository (or contact the
maintainer directly) rather than filing it as a routine bug — do not include
exploit details in a public issue for anything that would affect a future
deployed instance.

## Design controls already in place

- Backend binds `127.0.0.1` only outside production; production mode
  requires explicit, validated, non-wildcard origins and hostnames, and
  HTTPS for any non-loopback origin (`services/brain/config.py`).
- WebSocket/API messages use strict versioned schemas that reject unknown
  fields, invalid types, non-finite numbers, and oversized payloads.
- Checkpoints are loaded as NPZ with `allow_pickle=False`; array names,
  shapes, dtypes, byte sizes, and a SHA-256 are validated before any
  allocation. No pickle or other executable checkpoint format is accepted.
- Replays validate version, seed, action bounds, frame bounds, and byte
  size before playback; they contain no executable content.
- No `eval`/`exec`, no dynamic user-directed imports, no
  `dangerouslySetInnerHTML`, no client-supplied paths/URLs/shell commands.
- Connection/message rate limits, idle timeouts, and bounded backpressure
  on the WebSocket service; hard bounds on neurons/edges/episodes/training
  population and duration to prevent resource exhaustion.
- Debug hook `window.__FLYWEIGHT__` is only attached in development builds.

## Known gaps before any public deployment

- No TLS termination, reverse proxy, or production CORS/CSP profile is
  wired up outside local validation logic — see `AGENTS.md` Phase 2 notes
  and `BUILD_REPORT.md` for what remains.
- No authentication exists or is planned for this phase; a public instance
  would need rate limiting and abuse monitoring beyond the current local
  per-connection limits.
- No LICENSE has been chosen yet for the original source in this
  repository (see README's License section).
